## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| rede do host → containers publicados | Portas publicadas pelo compose são a superfície exposta na máquina do desenvolvedor |
| cliente HTTP → API Gateway | Único ponto de entrada pretendido do sistema; por D-05 ele não decide confiança, apenas encaminha |
| Docker Hub → runtime | Imagens de terceiros viram processos em execução aqui |
| `.env` local → repositório git | Segredos reais (token do LocalStack, senha do Postgres) ficam de um lado desta fronteira |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-11 | Spoofing | API Gateway encaminhando requisições sem validar JWT (D-05) | medium | accept | Decisão travada do usuário: o Gateway não adiciona confiança, apenas roteia; todo serviço downstream valida o token localmente e de forma independente (AUTH-03), então uma requisição não validada no Gateway não consegue elevar privilégio em lugar nenhum.
