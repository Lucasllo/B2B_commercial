## Decisões do planejador (Claude's Discretion) registradas por este plano

- Mesmo `CorrelationContext`/`CorrelationIdFilter` de 07-02, duplicado (`CORRELATION_CODE_PLACEMENT=duplicated-per-service`).
- `E2E_CORRELATION_PROOF=output-capture` — o E2E prova pelo log (as duas aplicações escrevem no mesmo
  `System.out` do JVM de teste), procurando o ID na mesma linha que o nome simples da classe do
  listener; logger names diferentes (`c.o.i…` × `c.o.o…`) distinguem os serviços.
- `LISTENER_COMPAT_OVERLOAD` — o método `onMessage(String)` fica como sobrecarga que delega com ID nulo,
  para testes unitários chamarem sem o atributo (Pitfall 5).
